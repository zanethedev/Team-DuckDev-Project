# Team DuckDev – Bathroom Sign-Out System
ICS4UO Team Development Project

## Accessing the Website
- Scan the provided QR code to open the website (leading to the student or teacher homepage)
- OR, visit: https://bathroom-signout-f88a9.firebaseapp.com/index.html
- No installation is required. The project runs directly in a browser.

## Basic Instructions
1. Open the website's homepage.
2. Select either Student or Teacher.

### Student Homepage
- Enter your student name and student number in the provided textboxes.
  - Student numbers must contain 6–7 digits.
- Click Sign Out when leaving. Your information and sign-out time will automatically be sent to the teacher dashboard.
- Click Sign In when returning. Your return time will automatically be recorded.

### Teacher Homepage
- Log in using the teacher password.
- View student sign-out records organized by school date and period.
- Select different periods to view their corresponding records.
- Use the date selector in the top right to view records from previous school days.
- Edit Tool:
  - Correct existing student information and/or sign-out/sign-in times
- Delete Tool:
  - Delete student information on the table
